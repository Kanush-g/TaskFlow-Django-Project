\# TaskFlow - Django Task Management System



TaskFlow is a Django-based task management web application developed as a college project.



\## Project Overview



TaskFlow helps users organize and manage their tasks. Users can create tasks, update them, delete them, and change their completion status.



Each task can contain a title, description, category, priority, and due date.



\## Features



\- Add new tasks

\- Edit existing tasks

\- Delete tasks

\- Mark tasks as completed or pending

\- Task categories

\- Low, Medium, and High priority

\- Due dates

\- Dashboard statistics

\- Completed and pending task indicators

\- Django Admin panel

\- Customized user interface

\- Celebration effect when all tasks are completed



\## Technologies Used



\- Python

\- Django

\- HTML

\- CSS

\- SQLite

\- Git

\- GitHub
